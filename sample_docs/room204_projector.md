# Room 204 — Projector & Laptop Setup

## Connecting a laptop
1. Use the **HDMI cable** in the wall plate at the lectern.
2. Press **INPUT** on the projector remote and select **HDMI 1**.
3. If there is no signal, press **Windows + P** and choose **Duplicate**.

## Equipment
- Projector model: **Epson EB-2250U**
- Default standby time: **10 minutes**
- Resolution: 1920x1200 (WUXGA)

## Troubleshooting: No image
1. Confirm the projector is powered on (blue LED).
2. Re-seat the HDMI cable at both ends.
3. Switch the laptop output to Duplicate (Windows + P).
4. Try the spare HDMI cable stored in the lectern drawer.
5. If still no image, escalate to Technical Services at extension 4500.

## Audio
- Room audio routes through the **Extron DMP 128** mixer.
- Default volume is set to 50%. The wall panel controls program volume only.
