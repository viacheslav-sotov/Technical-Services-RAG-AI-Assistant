# Technical-Services-RAG-AI-Assistant
AI-powered RAG assistant for Technical Services documentation, troubleshooting, and equipment manuals. Built with Python, ChromaDB, Ollama, and Streamlit.

Technical Services RAG Assistant is an AI-powered knowledge base designed to help event and AV staff quickly access technical documentation, troubleshooting guides, and equipment manuals through natural language questions. Built using Retrieval-Augmented Generation (RAG), the system combines a vector database with a large language model to provide accurate, source-grounded answers from internal Technical Services documents.

Features:

* PDF and document ingestion
* Semantic search with vector embeddings
* AI-generated answers with source citations
* Streamlit web interface
* Local LLM support via Ollama
* Easily expandable knowledge base for new equipment and procedures

Tech Stack: Python, LangChain, ChromaDB, SentenceTransformers, Ollama, Qwen, and Streamlit.
